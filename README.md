# 🎓 ТАСКИ — Трекер задач и рабочих часов (Сентябрь 2026 — Январь 2027+)

Удобный, легковесный веб-трекер для распределения учебных и рабочих задач с расчетом рабочих часов и перерывов.

## ✨ Возможности
- 📅 **Динамический календарь**: охватывает осенний семестр 2026/2027 (с 31 августа 2026 по 31 января 2027) с кнопкой бесконечного продления по 4 недели.
- 🎯 **Кнопка «Сегодня»**: быстрый скролл и подсветка текущего дня.
- 💼 / 🎓 **Раздельные режимы**: отдельные списки задач для Учебы и Работы.
- ☕ **Рабочее время и перерывы**: точный расчет фактически отработанных часов с учетом перерывов.
- ☁️ **Облачная синхронизация**: мгновенная синхронизация через GitHub Gist между ПК и смартфоном.
- 🔒 **Защита PIN-кодом**: экран блокировки для безопасности в общественных местах и на учебе.
- 📱 **Ссылка для мобильного**: автоматическая настройка синхронизации в один клик без ручного ввода токенов.
- 💾 **Резервное копирование**: экспорт и импорт базы в JSON.
- 🌓 **Темная и светлая темы**.
